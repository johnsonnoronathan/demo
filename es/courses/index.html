Cómo escribir casos de prueba

Escribe casos de prueba que cualquiera pueda ejecutar y que encuentren errores.

Los fundamentos de las pruebas, en lecciones breves. Aprende qué es un caso de prueba y qué lo hace fiable, elige entradas con particiones y valores límite, cubre los caminos infelices, convierte un caso escrito en una prueba automatizada y mantén sana una batería de pruebas que crece.

  • 7 lecciones
  • 7 vídeos
  • 1 h 45 min
  1. Fundamentos
  2. Diseño de casos de prueba
  3. Automatizar y escalar

02Intermedio28:22

Pruebas de rendimiento

Encuentra lo que hace lento el software antes que tus usuarios.

Aprende a probar el rendimiento de una aplicación web desde los dos lados. Las pruebas estáticas inspeccionan código, consultas y recursos sin ejecutar nada. Las pruebas dinámicas ejecutan el sistema, le envían tráfico y miden lo que sienten los usuarios. Practicarás ambas con Larkspur Books, una pequeña librería en línea lenta a propósito.

  • 14 lecciones
  • 22 vídeos
  • 6 h 50 min
  • 15 ejercicios prácticos
  1. Visión general
  2. Pruebas estáticas
  3. Pruebas dinámicas
  4. Resumen

API Testing

Check that an HTTP API answers the way it promises.

A short introduction to testing HTTP APIs. Learn the three things to check on every response (the status code, the shape of the body, and what happens when the request is wrong), try them by hand with curl, then turn them into automated checks that run against your own API.

  • 2 lecciones
  • 2 vídeos
  • 55 min
  • 1 ejercicios prácticos
  1. What to check
  2. Checks for your own API
