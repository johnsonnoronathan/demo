Pruebas de rendimiento

Encuentra lo que hace lento el software antes que tus usuarios.

Aprende a probar el rendimiento de una aplicación web desde los dos lados. Las pruebas estáticas inspeccionan código, consultas y recursos sin ejecutar nada. Las pruebas dinámicas ejecutan el sistema, le envían tráfico y miden lo que sienten los usuarios. Practicarás ambas con Larkspur Books, una pequeña librería en línea lenta a propósito.

Serás capaz de

  • Convertir «debería ser rápido» en presupuestos y umbrales medibles
  • Encontrar consultas N+1, índices que faltan y recursos pesados leyendo código, planes y compilaciones
  • Medir la carga de la página en laboratorio con Lighthouse y leer las Core Web Vitals
  • Escribir y ejecutar pruebas de carga, estrés, pico y resistencia con k6
  • Localizar un cuello de botella de CPU en un gráfico de llamas y demostrar la solución
  • Llevar las comprobaciones estáticas y dinámicas a CI e informar de resultados útiles
  • Ejecutar una prueba de aceptación con criterios acordados y registrar la decisión de publicar o no
  • Aplicar las comprobaciones estáticas a tu propio proyecto, con un agente que implementa las correcciones

Antes de empezar

Desarrolladores y testers que leen JavaScript y SQL y usan una terminal. No hace falta experiencia previa en pruebas de rendimiento.

  • Node.js 22.13 o posterior
  • Una terminal y un editor de código
  • Chrome, para Lighthouse y el perfilador de CPU
  • k6 para el capítulo 3 (el curso incluye también una herramienta de carga integrada)

Prepara la aplicación de práctica

cd academy/practice/larkspur
npm run seed
npm start   # leave it running in its own terminal; http://localhost:3000
