Testbench para agentes

Cada curso lo pueden leer tanto personas como máquinas. Esto es lo que puede usar un agente y cómo.

Prompts para agentes en los ejercicios

Cada ejercicio práctico tiene un botón Copiar prompt. El prompt es autosuficiente: dónde trabajar, los pasos, cómo saber que está hecho, qué informar y reglas como citar la salida real de los comandos en lugar de estimar. Las páginas sin ejercicio no tienen prompt.

You are doing a hands-on exercise from the "Performance Testing" course: Lesson 1.1, "What performance testing measures".

Exercise: Set up Larkspur and take a first measurement
Goal: Get the practice app running and record a baseline for /api/books: query count, p50, p95 and throughput at 10 users.

Project: academy/practice/larkspur (A Node.js 22 bookshop with a storefront and three JSON endpoints over SQLite. No dependencies. Slow on purpose.)
Setup, if not done already:
  cd academy/practice/larkspur
  npm run seed
  npm start   # leave it running in its own terminal; http://localhost:3000

Steps:
1. Run `npm run seed` and confirm it reports 500 authors, 5,000 books, 50,000 reviews and 200,000 orders.
2. Start the app with `npm start` in the background and wait until http://localhost:3000/health returns `ok`.

Una buena forma de trabajar

Haz primero el ejercicio tú mismo y luego deja que un agente lo repita o lo amplíe. Comprueba que cada número del informe del agente aparece en la salida que cita.

Testbench

Testbench enseña pruebas de software con vídeos breves narrados, lecciones pensadas para leer y ejercicios prácticos sobre aplicaciones reales de práctica. Cada ejercicio incluye un prompt que puedes pasar a un agente de programación.
