見て、読んで、手を動かして、ソフトウェアテストを学ぶ。

各レッスンは数分のナレーション付き動画から始まり、自分のペースで読めるレッスンに続き、実際の練習アプリでの演習で終わります。どの演習もワンクリックでコーディングエージェントに渡せます。

レッスンの進め方

  1. 1見る

    字幕・チャプター・速度調整付きの数分のナレーション動画。

  2. 2読む

    同じ内容を読むためのテキスト。アニメーションは一段ずつ進められます。

  3. 3やってみる

    練習アプリでのハンズオン。期待される画面のスクリーンショット付き。

  4. 4任せる

    演習のエージェント用プロンプトを Claude Code などにコピーします。
