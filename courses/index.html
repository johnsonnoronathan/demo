Writing Test Cases

Write test cases anyone can run, and that find bugs.

The foundations of testing, in short lessons. Learn what a test case is and what makes one trustworthy, choose inputs with partitions and boundaries, cover the unhappy paths, explore without a script, turn a written case into an automated test, and keep a growing suite healthy.

Performance Testing

Find what makes software slow before your users do.

Learn to test a web application's performance from both sides. Static testing inspects code, queries and assets without running anything. Dynamic testing runs the system, puts traffic through it and measures what users feel. You practise both on Larkspur Books, a small bookshop app that is slow on purpose.

  • 14 lessons
  • 22 videos
  • 6 h 50 min
  • 15 hands-on exercises
  1. Overview
  2. Static testing
  3. Dynamic testing

API Testing

Check that an HTTP API answers the way it promises.

A short introduction to testing HTTP APIs. Learn the three things to check on every response (the status code, the shape of the body, and what happens when the request is wrong), try them by hand with curl, then turn them into automated checks that run against your own API.
