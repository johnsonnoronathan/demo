check:
  - q: "A dashboard shows an average response time of 140 ms. Why isn't that enough to say the endpoint is fast?"
    a: "The average hides the tail. p95 could be several hundred milliseconds, meaning one user in twenty waits much longer. Ask for p95 and p99."
  - q: "Which family of test would you use to check, on every pull request, that no one adds a 600 KB script to the storefront?"
    a: "A static check: measure the assets against a budget at build time. It takes seconds and needs no running server."
  - q: "Your static checks all pass. Can you say the app handles 50 users at p95 under 300 ms?"
    a: "No. Static checks find known patterns; only a dynamic test under that load can show the p95 users would see."
  - q: "What must you record next to a measured p95 so someone else can repeat it?"
    a: "The endpoint, the number of virtual users and the duration, the machine, and the exact command."
