Écrire des cas de test

Écrivez des cas de test que tout le monde peut exécuter et qui trouvent des bugs.

Les fondamentaux du test, en courtes leçons. Découvrez ce qu'est un cas de test et ce qui le rend fiable, choisissez les entrées avec les partitions et les valeurs limites, couvrez les chemins d'erreur, transformez un cas écrit en test automatisé et gardez en bonne santé une suite qui grandit.

  • 7 leçons
  • 7 vidéos
  • 1 h 45 min
  1. Fondamentaux
  2. Concevoir des cas de test
  3. Automatiser et passer à l'échelle

02Intermédiaire28:22

Tests de performance

Trouvez ce qui ralentit un logiciel avant vos utilisateurs.

Apprenez à tester les performances d'une application web sous deux angles. Les tests statiques examinent le code, les requêtes et les ressources sans rien exécuter. Les tests dynamiques font tourner le système, lui envoient du trafic et mesurent ce que ressentent les utilisateurs. Vous pratiquez les deux sur Larkspur Books, une petite librairie en ligne lente à dessein.

  • 14 leçons
  • 22 vidéos
  • 6 h 50 min
  • 15 exercices pratiques
  1. Vue d'ensemble
  2. Tests statiques
  3. Tests dynamiques
  4. Synthèse

03Débutant3:33

API Testing

Check that an HTTP API answers the way it promises.

A short introduction to testing HTTP APIs. Learn the three things to check on every response (the status code, the shape of the body, and what happens when the request is wrong), try them by hand with curl, then turn them into automated checks that run against your own API.

  • 2 leçons
  • 2 vidéos
  • 55 min
  • 1 exercices pratiques
  1. What to check
  2. Checks for your own API
