Tests de performance

Trouvez ce qui ralentit un logiciel avant vos utilisateurs.

Apprenez à tester les performances d'une application web sous deux angles. Les tests statiques examinent le code, les requêtes et les ressources sans rien exécuter. Les tests dynamiques font tourner le système, lui envoient du trafic et mesurent ce que ressentent les utilisateurs. Vous pratiquez les deux sur Larkspur Books, une petite librairie en ligne lente à dessein.

Vous saurez

  • Transformer « ça devrait être rapide » en budgets et seuils mesurables
  • Trouver les requêtes N+1, les index manquants et les ressources lourdes en lisant le code, les plans et les builds
  • Mesurer le chargement d'une page en laboratoire avec Lighthouse et lire les Core Web Vitals
  • Écrire et exécuter des tests de charge, de stress, de pic et d'endurance avec k6
  • Repérer un goulot d'étranglement CPU dans un flame graph et prouver la correction
  • Intégrer les contrôles statiques et dynamiques à la CI et rendre compte de résultats exploitables
  • Mener un test d'acceptation selon des critères convenus et consigner la décision de mise en production
  • Appliquer les contrôles statiques à votre propre projet, avec un agent qui implémente les corrections

Avant de commencer

Développeurs et testeurs qui lisent JavaScript et SQL et savent utiliser un terminal. Aucune expérience des tests de performance n'est requise.

  • Node.js 22.13 ou plus récent
  • Un terminal et un éditeur de code
  • Chrome, pour Lighthouse et le profileur CPU
  • k6 pour le chapitre 3 (le cours fournit aussi un outil de charge intégré)

Préparer l'application d'entraînement

cd academy/practice/larkspur
npm run seed
npm start   # leave it running in its own terminal; http://localhost:3000
Testbench

Testbench enseigne les tests logiciels avec de courtes vidéos commentées, des leçons faites pour être lues et des exercices pratiques sur de vraies applications d'entraînement. Chaque exercice est accompagné d'un prompt à confier à un agent de programmation.
