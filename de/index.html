Test-Tutorials

Softwaretesten lernen: zuschauen, lesen, selbst machen.

Jede Lektion beginnt mit einem kommentierten Video von wenigen Minuten, geht als Text weiter, den Sie in Ihrem Tempo lesen, und endet mit einer Übung an einer echten Übungs-App. Jede Übung lässt sich mit einem Klick an einen Coding-Agenten übergeben.

So läuft eine Lektion ab

  1. 1Ansehen

    Ein kommentiertes Video von wenigen Minuten, mit Untertiteln, Kapiteln und einstellbarer Geschwindigkeit.

  2. 2Lesen

    Dieselbe Lektion als Text, im Lesetempo, mit Animationen, die Sie Schritt für Schritt durchgehen.

  3. 3Üben

    Eine praktische Übung an einer Übungs-App, mit Screenshots dessen, was Sie sehen sollten.

  4. 4Delegieren

    Kopieren Sie den Agenten-Prompt der Übung in Claude Code oder einen anderen Coding-Agenten.

Testbench

Testbench vermittelt Softwaretesten mit kurzen kommentierten Videos, gut lesbaren Lektionen und praktischen Übungen an echten Übungs-Apps. Zu jeder Übung gibt es einen Prompt, den Sie einem Coding-Agenten geben können.
