Testfälle schreiben

Schreiben Sie Testfälle, die jeder ausführen kann und die Fehler finden.

Die Grundlagen des Testens in kurzen Lektionen. Sie lernen, was ein Testfall ist und was ihn verlässlich macht, wählen Eingaben mit Äquivalenzklassen und Grenzwerten, decken die Fehlerpfade ab, machen aus einem geschriebenen Fall einen automatisierten Test und halten eine wachsende Testsuite gesund.

Performance-Tests

Finden Sie heraus, was Software langsam macht, bevor Ihre Nutzer es merken.

Lernen Sie, die Performance einer Webanwendung von beiden Seiten zu testen. Statische Tests untersuchen Code, Abfragen und Assets, ohne etwas auszuführen. Dynamische Tests lassen das System laufen, schicken Last darauf und messen, was Nutzer spüren. Beides üben Sie an Larkspur Books, einer kleinen Buchhandlungs-App, die absichtlich langsam ist.

API Testing

Check that an HTTP API answers the way it promises.

A short introduction to testing HTTP APIs. Learn the three things to check on every response (the status code, the shape of the body, and what happens when the request is wrong), try them by hand with curl, then turn them into automated checks that run against your own API.
