Testbench für Agenten

Jeder Kurs ist für Maschinen ebenso lesbar wie für Menschen. Das kann ein Agent nutzen, und so geht es.

Agenten-Prompts bei den Übungen

Jede praktische Übung hat eine Schaltfläche „Prompt kopieren“. Der Prompt ist in sich vollständig: wo gearbeitet wird, die Schritte, woran man das Ende erkennt, was zu berichten ist, und Regeln wie: echte Befehlsausgaben zitieren statt schätzen. Seiten ohne Übung haben keinen Prompt.

You are doing a hands-on exercise from the "Performance Testing" course: Lesson 1.1, "What performance testing measures".

Exercise: Set up Larkspur and take a first measurement
Goal: Get the practice app running and record a baseline for /api/books: query count, p50, p95 and throughput at 10 users.

Project: academy/practice/larkspur (A Node.js 22 bookshop with a storefront and three JSON endpoints over SQLite. No dependencies. Slow on purpose.)
Setup, if not done already:
  cd academy/practice/larkspur
  npm run seed
  npm start   # leave it running in its own terminal; http://localhost:3000

Steps:
1. Run `npm run seed` and confirm it reports 500 authors, 5,000 books, 50,000 reviews and 200,000 orders.
2. Start the app with `npm start` in the background and wait until http://localhost:3000/health returns `ok`.

Eine gute Arbeitsweise

Machen Sie eine Übung zuerst selbst und lassen Sie sie dann von einem Agenten wiederholen oder erweitern. Prüfen Sie, ob jede Zahl im Bericht des Agenten in der zitierten Ausgabe vorkommt.

Testbench

Testbench vermittelt Softwaretesten mit kurzen kommentierten Videos, gut lesbaren Lektionen und praktischen Übungen an echten Übungs-Apps. Zu jeder Übung gibt es einen Prompt, den Sie einem Coding-Agenten geben können.
