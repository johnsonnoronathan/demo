Performance-Tests

Finden Sie heraus, was Software langsam macht, bevor Ihre Nutzer es merken.

Lernen Sie, die Performance einer Webanwendung von beiden Seiten zu testen. Statische Tests untersuchen Code, Abfragen und Assets, ohne etwas auszuführen. Dynamische Tests lassen das System laufen, schicken Last darauf und messen, was Nutzer spüren. Beides üben Sie an Larkspur Books, einer kleinen Buchhandlungs-App, die absichtlich langsam ist.

Sie werden können

  • „Es soll schnell sein“ in messbare Budgets und Schwellenwerte übersetzen
  • N+1-Abfragen, fehlende Indizes und schwere Assets beim Lesen von Code, Plänen und Builds finden
  • Seitenladezeiten im Labor mit Lighthouse messen und Core Web Vitals lesen
  • Last-, Stress-, Spike- und Dauertests mit k6 schreiben und ausführen
  • Einen CPU-Engpass im Flame Graph finden und die Korrektur belegen
  • Statische und dynamische Prüfungen in die CI bringen und verwertbare Ergebnisse berichten
  • Einen Abnahmetest gegen vereinbarte Kriterien durchführen und die Go/No-Go-Entscheidung festhalten
  • Die statischen Prüfungen auf das eigene Projekt anwenden, wobei ein Agent die Korrekturen umsetzt

Bevor Sie anfangen

Entwickler und Tester, die JavaScript und SQL lesen und ein Terminal bedienen können. Erfahrung mit Performance-Tests ist nicht nötig.

  • Node.js 22.13 oder neuer
  • Ein Terminal und ein Code-Editor
  • Chrome für Lighthouse und den CPU-Profiler
  • k6 für Kapitel 3 (der Kurs enthält auch ein eingebautes Lastwerkzeug)

Die Übungs-App einrichten

cd academy/practice/larkspur
npm run seed
npm start   # leave it running in its own terminal; http://localhost:3000
Testbench

Testbench vermittelt Softwaretesten mit kurzen kommentierten Videos, gut lesbaren Lektionen und praktischen Übungen an echten Übungs-Apps. Zu jeder Übung gibt es einen Prompt, den Sie einem Coding-Agenten geben können.
