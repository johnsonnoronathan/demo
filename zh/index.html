测试教程

看、读、做，学会软件测试。

每节课先看一段几分钟的讲解视频，再按自己的节奏阅读课文，最后在真实的练习应用上完成练习。任何练习都可以一键交给编码智能体。

一节课怎么上

  1. 1看

    几分钟的讲解视频，带字幕、章节和可调语速。

  2. 2读

    同一节课的文字版，节奏适合阅读，动画可以逐步播放。

  3. 3做

    在练习应用上动手完成练习，附有应当看到的截图。

  4. 4交给智能体

    把练习的智能体提示词复制到 Claude Code 或其他编码智能体中。
