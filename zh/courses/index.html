01入门12:57

编写测试用例

写出任何人都能执行、并且能发现缺陷的测试用例。

用几节短课学习测试的基础：什么是测试用例、怎样的测试用例才可靠，用等价类划分和边界值选择输入，覆盖异常路径，把写好的用例变成自动化测试，并让不断增长的测试套件保持健康。

  • 7 节课
  • 7 个视频
  • 1 小时 45 分钟
  1. 基础
  2. 设计测试用例
  3. 自动化与规模化

02进阶26:52

性能测试

在用户发现之前，找出让软件变慢的原因。

学习从两个方向测试 Web 应用的性能。静态测试不运行任何东西，只检查代码、查询和资源；动态测试运行系统、向它发送流量，并测量用户的实际感受。你会在 Larkspur Books 上练习这两种方法，这是一个故意做得很慢的小型网上书店。

  • 14 节课
  • 22 个视频
  • 6 小时 50 分钟
  • 15 个动手练习
  1. 概述
  2. 静态测试
  3. 动态测试
  4. 总结

03入门3:33

API Testing

Check that an HTTP API answers the way it promises.

A short introduction to testing HTTP APIs. Learn the three things to check on every response (the status code, the shape of the body, and what happens when the request is wrong), try them by hand with curl, then turn them into automated checks that run against your own API.
