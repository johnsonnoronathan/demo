# 第 1 章 · 开篇: 概述

性能测试 · 第 1 章: 概述 · 5 分钟

> 这门课程讲什么、如何组织，以及如何使用课堂和其中的智能体提示词。

## 文字稿: 概述 (1:45)

**0:00 欢迎.** 欢迎来到 Testbench 的性能测试课程。在这门课里，你将学会在用户发现之前，找出让软件变慢的原因。 “网站感觉很慢”只是一句抱怨。附上原因的数字，才是一个发现。这门课教你从前者走到后者。

**0:18 四个章节.** 课程分为四章。首先是概述：性能测试测量什么，以及怎么测。 然后是静态测试：不运行任何东西，通过阅读代码、查询计划和构建输出来发现问题。 接着是动态测试：在真实的流量下运行应用，测量用户的实际感受。 最后是总结：把两者结合成一套工作流程，并写成一份能让人据此行动的报告。

**0:48 练习应用.** 你将在 Larkspur Books 上练习，这是一个小型网上书店，有 5,000 本书和 200,000 个订单。 它是故意做得很慢的。一页图书要执行 101 次数据库查询，在手机上，主图要将近 10 秒才能显示出来。 学完这门课，你会找出并修复其中的每一个问题，而且每项修复都有数字为证。

**1:11 每个页面怎么用.** 每个页面的用法都一样。先看一段简短的视频，就像这一段。 然后按自己的节奏，阅读视频下方的课程内容。 接着完成动手练习中你的部分：亲自运行检查，读懂数字。 把实现交给编程智能体。复制练习的提示词，智能体会完成修复，并引用它的输出。 然后验证：亲自重新运行同样的检查。你看到的数字才算数，决定也由你来做。

## 课文

“网站感觉很慢”是一句抱怨。“`/api/books` 的 p95 是 1.3 秒，而预算是 300 ms，因为这个接口每个请求要执行 101 次查询”则是一个别人能着手修复的发现。这门课教你可靠地从前者走到后者。

## 你将收获什么

- 了解性能测试回答哪些问题，以及它报告哪些数字
- 分清静态测试和动态测试，知道各自在什么时候最划算
- 让练习应用跑起来，并记下第一次测量结果
- 知道如何把动手练习交给编程智能体，以及它汇报时要检查什么

## 课程如何组织

课程从全局出发，深入具体技术，最后再回到全局。第 1 章界定问题。第 2 章和第 3 章各自深入讲解一类测试。第 4 章把它们组合成一套工作流程和一份报告。

1. **概述** (总): 性能测试测量什么、两类测试方法，以及练习用的应用。
2. **静态测试** (分): 不运行系统，通过检查你构建的东西来发现性能问题。
3. **动态测试** (分): 运行系统、发送流量，测量用户的实际感受。
4. **总结** (总): 把两者结合成一套工作流程，报告结果，进行验收，应用到你自己的项目，并回顾整门课程。

每一章的结构都相同：

1. **开篇**，就像本页：你将收获什么，以及本章的地图。
2. **课程**。每节课都兼有概念和实践。概念配有一段简短的**动画**，可以播放、暂停和逐步查看。动手练习在练习应用上进行，并附有你应该看到的**截图**。
3. **小结**，汇总本章要点，并提供几道自测题。

## 练习应用

你测试的一切都基于 **Larkspur Books**，它是位于 `academy/practice/larkspur` 的一个小型书店：一个店面页面和三个 JSON 接口，背后是一个 SQLite 数据库，包含 5,000 本书、50,000 条评论和 200,000 个订单。它只需要 Node.js 22.13 或更高版本，别无其他依赖。

Larkspur 是故意做得很慢的。其中每个问题都是本课程要教你发现的，课程中引用的每个数字都来自对它的真实运行。你的数字会因机器不同而不同，但结果的趋势不会变。

## 与智能体协作

这门课教你测试性能，智能体帮你完成工作。每个练习中的分工都一样：

| 你 | 智能体 |
| --- | --- |
| 学习概念：看视频、读课程 | |
| 运行检查和测试，读懂数字 | |
| | 实现：修复、脚本、门禁、CI 配置 |
| | 汇报结果，引用真实的命令输出 |
| 验证：重新运行同样的检查并比较 | |
| 决定：验收、拒绝，或设定新的预算 | |

每个练习都分两部分。先是**你的部分**：你亲自运行的步骤，以及你应该看到的输出。然后是**智能体的部分**：一段提示词，你把它复制到 Claude Code 或其他编程智能体中，由它完成改动。提示词是自包含的：在哪里操作、步骤、如何判断完成，以及要汇报什么。它要求智能体引用真实的输出而不是估算，并且绝不为了让检查通过而放宽预算。

当智能体说已经完成时，亲自重新运行一遍检查。你看到的数字才算数。到课程结束时，你会在自己的项目上使用同样的循环（第 4.4 课），并以一次正式的验收决定收尾（第 4.3 课）。

> **智能体可以阅读整门课程.** 每个页面都有一个 Markdown 版本（见页边的“For agents”），`/llms.txt` 列出了全部页面。当智能体需要单个练习之外的上下文时，把它指向那里。
